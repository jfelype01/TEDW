# CAMPUS+ — Eventos Acadêmicos

Projeto de atividade prática de Bootstrap, baseado na linguagem visual editorial/contemporânea do site de referência indicado pelo aluno e adaptado ao desafio do PDF.

## Requisitos do PDF
- Navbar + identidade
- Hero
- 3 eventos em cards
- Organização/filtro visual por categoria
- Detalhes de eventos em modal
- Footer
- Responsividade
- Grid Bootstrap
- Mais de 3 componentes Bootstrap além da navbar
- 3 integrantes identificados

## Antes de entregar
Troque os três placeholders de integrantes no `index.html`.
Teste os modais, menu mobile e layout em diferentes larguras.
Publique no GitHub Pages e entregue o link público + repositório.
